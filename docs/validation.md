## 자동 테스트와 통합 검증

Windows, Python 3.12.9, Django 6.1에서 기존 자동 테스트 **136개 통과**, Django 시스템 검사 **0건**, 마이그레이션 변경 **없음**을 확인했습니다. [테스트 실행 명령](../README.md#테스트와-검증)

- **Django 자동 테스트** — 모델과 제약, 시드 재실행, Mock 응답 검증과 저장 롤백, 할인·추천 경계값, 인증·카드·추천·이용내역 화면을 검증했습니다.
- **격리 실제 HTTP와 브라우저** — 가입, 로그인, 카드 등록, 추천, 이용내역, 로그아웃 흐름을 확인했습니다. 사용자별 카드·거래 격리, CSRF 검증, 상태 변경 요청의 POST 제한을 확인했습니다.
- **Mock 실제 HTTP** — Bearer 인증 후 정상 거래 두 건의 필드와 저장 후 화면 반영을 확인했습니다. 인증 실패, 미등록 카드 식별자, 연결 실패, 소유권 불일치를 검증했습니다. 별도 로컬 오류 응답에서 잘못된 JSON과 유효·무효 거래가 섞인 배치가 저장되지 않았습니다. DB 저장 도중 오류 시 롤백은 자동 테스트로 확인했습니다.
- **추천 고정 시각** — 2026년 11월 기준 당월 177,500원·5건, 전월 300,000원, 카드 E 사용 추정 9,000원·잔여 1,000원을 확인했습니다. 음식점 50,000원에서는 D 6,000원, 19,999원은 C 1,999원, 20,000원은 D 2,400원, 30,000원은 D 3,600원이었고 카페 50,000원에서는 추천이 없었습니다.
- **브라우저 레이아웃과 접근성** — 주요 화면 7개와 긴 이름·금액을 넣은 화면 4개를 Chrome의 1440·1280·768·390·360px에서 검사해 55개 조합을 확인했습니다. 색상에 의존하던 메뉴와 빠른 금액 선택 표시를 하단 표시선과 체크로 보완했습니다. 같은 5개 폭에서 키보드 포커스, 버튼 이름과 상태, 잘림과 가로 스크롤, JavaScript 없이 기본 추천 요청을 재확인했습니다. 360px 회색조 화면도 확인했습니다.

## 독립 환경 재현

같은 Windows에서 최종 작업 트리를 별도 폴더에 복사했습니다. 새 가상환경에 `requirements.txt`를 설치하고 새 `.env`와 SQLite DB를 만들었습니다. 마이그레이션 후 첫 시드에서 카드 5개와 혜택 5개를 생성했고 두 번째 시드는 기존 행을 재사용했습니다. `pip check`, Django 시스템과 마이그레이션 검사, 자동 테스트 136개가 모두 통과했습니다.

Chrome에서 신규 가입 후 테스트카드 A를 등록하고 음식점 50,000원에서 2,500원 예상 할인을 확인했습니다. 기존 Mock 서버와 관리 명령으로 거래 두 건을 가져왔고, 2026년 11월 이용내역에서 두 거래와 합계 27,500원을 확인했습니다. 홈과 카드 상세에도 당월 27,500원이 반영됐습니다.

## 로컬 성능 측정

Phase E에서 Windows, 격리 SQLite, Django 테스트 클라이언트로 측정했습니다. 각 화면을 한 번 예열한 뒤 5회 측정한 서버 측 응답 시간 중앙값입니다. 운영 환경이나 브라우저의 체감 응답 시간을 보장하지 않습니다.

| 화면 | 보유 카드 | 거래 | 쿼리 수 | 응답 시간 중앙값 |
| --- | ---: | ---: | ---: | ---: |
| 추천 | 1장 | 0건 | 14 | 8.29ms |
| 추천 | 25장 | 50건 | 134 | 59.03ms |
| 추천 | 25장 | 1,000건 | 134 | 60.62ms |
| 이용내역 | 25장 | 50건 | 10 | 18.34ms |
| 이용내역 | 25장 | 1,000건 | 10 | 162.59ms |

추천은 카드마다 실적과 혜택을 조회하므로 카드 수에 따라 쿼리가 늘었습니다. 이용내역은 쿼리 수가 일정했지만 전체 거래를 한 화면에 렌더링하는 시간이 늘었습니다.

## 미검증 범위

모바일은 브라우저 뷰포트로, 접근성은 키보드와 Chrome 접근성 트리로 확인했습니다. 실제 모바일 기기, 실제 스크린리더, 다른 Windows 기기에서의 설치, 운영 배포와 운영 보안은 검증하지 않았습니다.
